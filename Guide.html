NAI Review Viewer

NAI 검수 뷰어 사용 가이드NAI Review Viewer GuideNAI 検品ビューア ガイド

수백~수천 장의 NovelAI 이미지를 눈으로 빠르게 훑고, 불합격 컷에만 사유를 체크하는 Windows용 로컬 앱입니다. 인터넷으로 아무것도 보내지 않습니다. A local Windows app for skimming hundreds or thousands of NovelAI images by eye and marking only the ones that fail. Nothing is sent over the internet. 数百〜数千枚の NovelAI 画像をすばやく目視確認し、不合格の画像にだけ理由をチェックする Windows 用ローカルアプリです。インターネットには何も送信しません。

  2. zip을 우클릭 → 속성 → 아래쪽 차단 해제에 체크 → 확인. 그다음 원하는 곳에 압축을 풉니다. (예: C:\NAI-Review-Viewer)

"Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누르세요. 서명이 없는 프로그램에 처음 한 번 뜨는 안내입니다.

2. 시작하기2. Quick start2. はじめに

  1. 폴더 열기. 뷰어 왼쪽 위 📁(Ctrl+O)에서 이미지 폴더 경로를 붙여 넣거나 찾아보기로 고릅니다. 폴더를 NAI-Review-Viewer.bat 위에 끌어다 놓아도 됩니다.
  2. 훑어보기. →로 다음 페이지로 넘깁니다. 화면에 잠깐(0.45초) 머문 이미지는 "본 것"으로 기록됩니다.
  3. 문제 있는 컷만 체크. 마우스를 올린 칸에서 숫자 키 1~9를 누릅니다. 아무 체크 없이 본 이미지는 합격입니다.
  4. 내보내기. 다 보면 ⇩ 내보내기(Ctrl+E)를 누릅니다. 불합격 목록과 사유가 폴더 안 _review에 저장됩니다.

언어는 Windows 표시 언어를 따라가고, 뷰어의 ⚙ 설정 맨 위 Language에서 바꿀 수 있습니다. 뷰어를 끝내려면 검은 콘솔 창을 닫습니다. 다시 열면 마지막으로 보던 자리에서 이어집니다.

  1. Open a folder. Click 📁 at the top left (Ctrl+O) and paste the image folder path or browse for it. You can also drag a folder onto NAI-Review-Viewer.bat.
  2. Skim. Press → for the next page. An image that stays on screen briefly (0.45 s) is recorded as "seen".
  3. Mark only the problem images. Hover over a cell and press a number key 1–9. A seen image with no mark is a pass.
  4. Export. When you finish, press ⇩ Export (Ctrl+E). The reject list and reasons are saved in _review inside the folder.

The language follows the Windows display language; change it under Language at the top of ⚙ Settings. To quit, close the black console window. Next time the viewer resumes where you left off.

  1. フォルダを開く。左上の 📁(Ctrl+O)で画像フォルダのパスを貼り付けるか、参照で選びます。フォルダを NAI-Review-Viewer.bat にドラッグ&ドロップしても開けます。
  2. ざっと見る。→ で次のページへ進みます。画面に少しの間(0.45 秒)表示された画像は「確認済み」と記録されます。
  3. 問題のある画像だけチェック。マウスを乗せたセルで数字キー 1〜9 を押します。チェックなしで確認した画像は合格です。
  4. 書き出し。見終わったら ⇩ 書き出し(Ctrl+E)を押します。不合格のリストと理由がフォルダ内の _review に保存されます。

言語は Windows の表示言語に従い、⚙ 設定の一番上の Language で変更できます。終了するには黒いコンソールウィンドウを閉じます。次回は最後に見ていた位置から再開します。

5. 여러 장 한꺼번에 · 삭제5. Bulk actions and delete5. 複数枚の操作・削除

  • 선택: Ctrl+클릭 또는 X로 하나씩, Shift+클릭으로 범위, 마우스를 누른 채 훑어서 여러 칸. Ctrl+A는 이 페이지 전부입니다. 선택이 있으면 체크·메모·삭제가 선택 전부에 적용됩니다.
  • 일괄 합격 (P): 체크하지 않은 "안 본" 이미지를 한 번에 본 것(합격)으로 처리합니다. 선택한 것, 지금 페이지까지, 목록 전체 중에서 고릅니다.
  • 삭제 (Del): Windows 휴지통으로 보냅니다. 휴지통에서 복원할 수 있고, 삭제 전 체크는 내보내기 결과에 남습니다.
  • Select: Ctrl+click or X for single cells, Shift+click for a range, or drag across cells with the mouse button held. Ctrl+A selects the whole page. With a selection, marks, notes and delete apply to all selected images.
  • Pass all (P): records unmarked "unseen" images as seen (passed) in one go. Choose the selection, everything up to this page, or the whole list.
  • Delete (Del): sends files to the Windows Recycle Bin. You can restore them from there, and their marks stay in the export.
  • 選択: Ctrl+クリックまたは X で 1 つずつ、Shift+クリックで範囲、マウスを押したままなぞると複数セル。Ctrl+A はこのページすべてです。選択中は、チェック・メモ・削除が選択したすべての画像に適用されます。
  • 一括合格 (P): チェックのない「未確認」の画像をまとめて確認済み(合格)にします。選択したもの、現在のページまで、リスト全体から選びます。
  • 削除 (Del): Windows のごみ箱に送ります。ごみ箱から復元でき、削除前のチェックは書き出し結果に残ります。

6. 검열 덧칠6. Censor touch-up6. 修正加筆

그림은 좋은데 검열만 약한 컷을 다시 뽑지 않고 그 자리에서 고칩니다. 칸에서 E를 누르면 편집 화면이 열립니다.

  • 1 블러 · 2 모자이크 · 3 먹칠, B 브러시 · R 사각형, [ ] 굵기, Shift+휠 세기
  • Space를 누르고 있으면 원본과 비교, Ctrl+Z 마지막 획 되돌리기
  • Enter 저장, Shift+Enter 저장하고 다음 "검열 약함" 컷 열기, Esc 취소

저장하면 같은 파일에 덮어쓰고, 그 컷의 "검열 약함" 체크만 풀립니다. 다른 불합격 사유가 남아 있으면 계속 불합격입니다. 처음 덧칠할 때 원본을 뷰어의 data 폴더에 한 번 보관하므로, 다시 E로 열어 원본 복원을 누르면 되돌릴 수 있습니다. 이미지에 들어 있는 생성 정보(프롬프트·seed)는 그대로 남습니다.

먼저 9로 훑으며 체크해 두고, 첫 컷에서 E → 칠하기 → Shift+Enter를 반복하면 체크한 컷을 차례로 고칠 수 있습니다.

Fix an image that is fine except for weak censoring, on the spot and without regenerating it. Press E on a cell to open the editor.

  • 1 blur · 2 mosaic · 3 black fill, B brush · R rectangle, [ ] size, Shift+wheel strength
  • Hold Space to compare with the original, Ctrl+Z to undo the last stroke
  • Enter save, Shift+Enter save and open the next "Weak censoring" image, Esc cancel

Saving overwrites the same file and clears its "Weak censoring" mark. Any other reject reasons still apply. The first time you touch up a file, the original is kept once in the viewer's data folder; open the image with E again and press Restore original to go back. The generation info inside the image (prompt, seed) is preserved.

Skim first and mark with 9; then on the first image press E → paint → Shift+Enter, and repeat to fix the marked images one after another.

絵は良いのに修正だけが弱い画像を、再生成せずにその場で直します。セルで E を押すと編集画面が開きます。

  • 1 ぼかし · 2 モザイク · 3 黒塗り、B ブラシ · R 矩形、[ ] 太さ、Shift+ホイール 強さ
  • Space を押している間は元画像と比較、Ctrl+Z で最後のストロークを取り消し
  • Enter 保存、Shift+Enter 保存して次の「修正が弱い」画像を開く、Esc キャンセル

保存すると同じファイルに上書きされ、その画像の「修正が弱い」のチェックだけが外れます。他の不合格理由が残っていれば、判定は引き続き不合格です。最初に加筆するとき、元画像をビューアの data フォルダに一度だけ保管するので、もう一度 E で開いて 元画像に戻す を押せば戻せます。画像に含まれる生成情報(プロンプト・seed)はそのまま残ります。

先に 9 でチェックしながら見て、最初の画像で E → 塗る → Shift+Enter を繰り返すと、チェックした画像を順番に直せます。

7. 결과 내보내기7. Export7. 書き出し

⇩ 내보내기(Ctrl+E)를 누르면 기본 설정에서는 현재 폴더의 _review에 아래 최신 파일과 시각별 사본이 저장됩니다. 목록 모드에서는 목록 파일 옆의 _review에 저장됩니다.

  • review-latest.md — 사람이 읽기 좋은 요약: 불합격 목록(사유·메모·seed), 세트 대표, 추가 생산 요청, 삭제한 파일
  • review-latest.json — 같은 내용을 프로그램·LLM이 읽기 좋은 형태로. 불합격 컷의 프롬프트 원문도 들어 있습니다

내보내기 창에서 요약이나 불합격 파일명 목록을 바로 복사할 수도 있습니다. 태그 없이 아직 안 본 컷이라도 같은 세트에 ★대표가 있으면 세트 탈락으로 기록됩니다. 판정이 남은 컷을 한꺼번에 합격 처리하려면 P를 누르세요.

Press ⇩ Export (Ctrl+E) to save the latest results and timestamped copies. By default, the _review folder is inside the current folder, or beside the list file in list mode.

  • review-latest.md — a readable summary: the reject list (reasons, notes, seeds), set picks, make-more requests, deleted files
  • review-latest.json — the same content for programs and LLMs, including the full prompts of rejected images

You can also copy the summary or the list of rejected filenames straight from the export dialog. An unseen, unmarked image is dropped from its set if the set has a ★ pick. To pass images that still have no verdict, use P (Pass all).

⇩ 書き出し(Ctrl+E)を押すと、最新の結果と日時付きのコピーが保存されます。既定の保存先は、現在のフォルダ内（リストモードではリストファイルと同じ場所）の _review です。

  • review-latest.md — 人が読みやすい要約: 不合格のリスト(理由・メモ・seed)、セット代表、追加生産の依頼、削除したファイル
  • review-latest.json — 同じ内容をプログラムや LLM が読みやすい形で。不合格画像のプロンプト原文も含まれます

書き出しのダイアログから、要約や不合格ファイル名のリストをそのままコピーすることもできます。未確認でチェックがない画像も、同じセットに ★代表があれば「セット落ち」になります。まだ判定のない画像をまとめて合格にするには P を押します。

8. LLM 연결 (선택)8. Connect an LLM (optional)8. LLM 接続 (任意)

뷰어는 혼자서 완결됩니다. Claude Code나 Codex 같은 코딩 에이전트를 쓰고 있다면, 아래 프롬프트를 한 번 붙여 넣는 것으로 "검수 결과를 읽고 불합격 컷을 다시 뽑는" 흐름에 연결할 수 있습니다.

  1. 설치 폴더의 Copy-LLM-Prompt.bat을 더블클릭합니다. 이 PC의 실제 경로가 들어간 연결 프롬프트가 클립보드에 복사됩니다.
  2. Claude Code·Codex 대화창에 붙여 넣고 보냅니다. 에이전트가 자기 지침 파일(CLAUDE.md / AGENTS.md)에 뷰어 사용법을 적어 둡니다.
  3. 이후에는 검수를 마치고 "검수 끝났어"라고 말하면 됩니다.

bat을 쓰지 않으려면 아래에 설치 폴더 경로를 넣고 복사하세요.

The viewer is complete on its own. If you use a coding agent such as Claude Code or Codex, pasting the prompt below once connects it to a "read the review results and regenerate the rejects" workflow.

  1. Double-click Copy-LLM-Prompt.bat in the install folder. A connection prompt containing this PC's real paths is copied to the clipboard.
  2. Paste it into your Claude Code or Codex chat and send it. The agent writes how to use the viewer into its own instruction file (CLAUDE.md / AGENTS.md).
  3. From then on, finish a review and just say "review done".

If you prefer not to use the bat, enter the install folder path below and copy.

ビューアは単体で完結します。Claude Code や Codex などのコーディングエージェントを使っている場合は、下のプロンプトを一度貼り付けるだけで「検品結果を読んで不合格の画像を再生成する」流れに接続できます。

  1. インストールフォルダの Copy-LLM-Prompt.bat をダブルクリックします。この PC の実際のパスが入った接続プロンプトがクリップボードにコピーされます。
  2. Claude Code・Codex のチャットに貼り付けて送信します。エージェントが自分の指示ファイル(CLAUDE.md / AGENTS.md)にビューアの使い方を書き込みます。
  3. 以後は、検品を終えて「検品終わった」と伝えるだけです。

bat を使わない場合は、下にインストールフォルダのパスを入力してコピーしてください。

에이전트가 참고하는 상세 문서는 설치 폴더의 LLM-CONNECT.md입니다(명령, 판정 규칙, JSON 필드). The detailed reference the agent reads is LLM-CONNECT.md in the install folder (commands, verdict rules, JSON fields). エージェントが参照する詳細文書は、インストールフォルダの LLM-CONNECT.md です(コマンド、判定ルール、JSON フィールド)。

9. 설정 · 업데이트 · 삭제9. Settings · update · uninstall9. 設定・アップデート・アンインストール

  • 화면 설정(⚙): 언어, 체크 후 자동으로 다음 칸, 칸 배경, 썸네일 화질, 삭제 확인 등.
  • 체크 항목 바꾸기: 설치 폴더의 config.json을 config.local.json으로 복사해서 고치세요. 이 파일이 있으면 그쪽을 쓰고, 업데이트해도 덮어쓰이지 않습니다. 사유의 이름·키·색·LLM용 해설을 바꾸거나 항목을 더할 수 있습니다(고친 뒤 뷰어 재시작).
  • 포트: 기본 8765. 다른 프로그램과 겹치면 같은 파일의 port를 바꿉니다.
  • 업데이트: 새 버전 zip을 풀고, 이전 폴더의 data 폴더(검수 기록·덧칠 원본)와 config.local.json을 새 폴더로 옮깁니다.
  • 삭제: 설치 폴더를 지우면 됩니다. 썸네일 캐시는 %LOCALAPPDATA%\nai-review-viewer에 있으며 지워도 됩니다.

검수 기록은 파일의 전체 경로를 기준으로 저장됩니다. 검수한 이미지를 뷰어 밖에서 옮기거나 이름을 바꾸면 그 이미지의 체크는 이어지지 않습니다.

  • Display settings (⚙): language, auto-advance after marking, cell background, thumbnail quality, delete confirmation and more.
  • Changing the reasons: copy config.json in the install folder to config.local.json and edit the copy. When that file exists it is used instead, and updates never overwrite it. You can change each reason's name, key, color and LLM hint, or add reasons (restart the viewer afterwards).
  • Port: 8765 by default. If it clashes with another program, change port in the same file.
  • Updating: extract the new zip, then move the data folder (review records and touch-up originals) and config.local.json from the old folder into the new one.
  • Uninstalling: delete the install folder. The thumbnail cache is in %LOCALAPPDATA%\nai-review-viewer and can be deleted too.

Review records are stored by each file's full path. If you move or rename reviewed images outside the viewer, their marks do not follow.

  • 表示設定(⚙): 言語、チェック後に自動で次のセルへ、セル背景、サムネイル画質、削除の確認など。
  • チェック項目の変更: インストールフォルダの config.json を config.local.json にコピーして編集してください。このファイルがあるとそちらが使われ、アップデートしても上書きされません。理由の名前・キー・色・LLM 向けの解説を変えたり、項目を追加したりできます(編集後にビューアを再起動)。
  • ポート: 既定は 8765。他のプログラムと重なる場合は同じファイルの port を変更します。
  • アップデート: 新しい zip を展開し、古いフォルダの data フォルダ(検品記録・加筆前の元画像)と config.local.json を新しいフォルダに移します。
  • アンインストール: インストールフォルダを削除します。サムネイルのキャッシュは %LOCALAPPDATA%\nai-review-viewer にあり、削除してかまいません。

検品記録はファイルのフルパスを基準に保存されます。検品した画像をビューアの外で移動・改名すると、その画像のチェックは引き継がれません。
