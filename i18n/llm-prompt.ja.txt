NAI 検品ビューア(人が画像を目で検品するローカルアプリ)をこの作業環境に接続してください。

1. まずこの文書を読んでください: {doc}
2. あなたが毎セッション読む指示ファイルに「NAI 検品ビューア」の節を追加してください。Claude Code なら CLAUDE.md、Codex なら AGENTS.md で、このプロジェクトになければユーザー全体の指示ファイルに入れてください。内容は 10 行以内で、次の項目だけにしてください。
   - ビューアを開く: "{py}" "{script}" "<画像フォルダ>"
   - 検品結果を読む: "{py}" "{script}" export "<画像フォルダ>" --print json
   - 判定ルールの要約: チェックなしの確認済み = 合格、否定の理由 = 不合格(再生成)、★代表があるセットの残り = セット落ち(再生成不要)、+追加 = 合格 + 追加生産、未確認 = 判定なし、修正を加筆したもの = 再生成不要
   - 詳しいルールと JSON のフィールドは {doc} を参照
3. 次のコマンドが動くか確認してください: "{py}" "{script}" export --help
4. どのファイルに何を追加したか教えてください。

今後、私が「検品終わった」と言ったら、検品結果を読み、不合格の画像を理由別に整理して、どう直して再生成するかを提案してください。画像ファイルの削除や上書きは、私が頼んだときだけ行ってください。
