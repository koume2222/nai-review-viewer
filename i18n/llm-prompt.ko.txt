NAI 검수 뷰어(사람이 이미지를 눈으로 검수하는 로컬 앱)를 이 작업 환경에 연결해 줘.

1. 먼저 이 문서를 읽어: {doc}
2. 네가 매 세션 읽는 지침 파일에 「NAI 검수 뷰어」 절을 추가해 줘. Claude Code면 CLAUDE.md, Codex면 AGENTS.md이고, 지금 프로젝트에 없으면 사용자 전역 지침 파일에 넣어. 내용은 10줄 이내로 다음만 적어.
   - 뷰어 열기 (PowerShell): & '{py}' '{script}' '<이미지 폴더>'
   - 검수 결과 읽기: & '{py}' '{script}' export '<이미지 폴더>' --print json
   - 판정 규칙 요약: 체크 없이 본 것 = 합격, 부정 사유 = 불합격(재생성), ★대표 세트의 태그 없는 다른 컷 = 세트 탈락(재생성 불필요), +추가 = 합격 + 추가 생산, unseen[] = 판정 없음, 검열 덧칠은 검열 사유만 해결하므로 다른 불합격 사유가 남으면 재생성
   - 상세 규칙과 JSON 필드는 {doc} 참조
3. 다음 명령이 도는지 확인해 줘: & '{py}' '{script}' export --help
4. 어느 파일에 무엇을 추가했는지 알려 줘.

앞으로 내가 "검수 끝났어"라고 하면 검수 결과를 읽고, 불합격 컷을 사유별로 정리한 다음 어떻게 고쳐 다시 뽑을지 제안해 줘. 이미지 파일을 지우거나 덮어쓰는 일은 내가 시킬 때만 해.
